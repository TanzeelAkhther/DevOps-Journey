# Engineering Decision Log

Record decisions that affect the learning environment, project architecture, tooling, security, or operations.

## How to record a decision

For each decision capture:
- ID and date.
- Status: proposed, accepted, superseded, or deprecated.
- Context and constraints.
- Options considered.
- Decision and rationale.
- Consequences, risks, and follow-up actions.
- Conditions that would cause the decision to be revisited.
