# DevOps Journey

A build-first engineering academy and portfolio documenting the journey toward independently designing, building, deploying, securing, troubleshooting, and operating production-grade infrastructure and platforms.

## How to use this repository

- Start with [the roadmap](00-MASTER-ROADMAP.md) for the learning sequence and capability gates.
- Read [the technical profile](01-TECHNICAL-PROFILE.md) for the current baseline and open questions.
- Use [the engineering portfolio](02-ENGINEERING-PORTFOLIO.md) to record projects and architecture.
- Update [learning progress](03-LEARNING-PROGRESS.md) after each meaningful session.
- Track unresolved weaknesses and practical tests in [engineering challenges](04-ENGINEERING-CHALLENGES.md).
- Record important technical choices in [the decision log](05-DECISION-LOG.md).

## Engineering principles

1. Build and test real systems; do not treat passive reading as competence.
2. Explain the why, trade-offs, failure modes, and operational consequences.
3. Prefer small, reproducible, version-controlled changes.
4. Include security, reliability, observability, and cost in design decisions.
5. Never record a skill as complete without practical evidence.
6. Keep secrets, credentials, private keys, tokens, and sensitive personal data out of Git.
