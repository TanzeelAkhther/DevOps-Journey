# CI/CD and Release Engineering

## Outcomes
- Design automated validation, build, security checks, artifact publishing, and deployment.
- Understand pipeline triggers, permissions, secrets, caching, artifacts, and environments.
- Implement safe releases, rollback, and traceability.

## Practical work
- Build a pipeline that tests and packages a sample application.
- Publish an immutable artifact.
- Add dependency and container checks.
- Demonstrate a failed pipeline and a controlled rollback.

## Evidence
Store workflow definitions with the relevant project. Do not add credentials or plaintext secrets. Competence is not assessed yet.
