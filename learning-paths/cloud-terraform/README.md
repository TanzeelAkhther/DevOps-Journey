# Cloud and Terraform

## Outcomes
- Understand cloud identity, networking, compute, storage, managed services, and cost controls.
- Provision infrastructure declaratively and manage state safely.
- Review plans, detect drift, and make controlled changes.

## Practical work
- Begin with local Terraform exercises before using billable cloud resources.
- Build a small network and compute environment in a chosen provider.
- Separate reusable modules from environment configuration.
- Document state protection, access control, destroy procedures, and cost estimates.

## Constraints
Cloud provider, account availability, region, and budget are not yet known. Confirm these before provisioning resources. Never commit state files containing sensitive data or credentials.
