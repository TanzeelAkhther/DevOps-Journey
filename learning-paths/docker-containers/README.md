# Docker and Containers

## Outcomes
- Explain images, layers, registries, containers, namespaces, cgroups, networking, and volumes.
- Build reproducible images and run containers safely.
- Diagnose build, startup, networking, storage, and resource problems.

## Practical work
- Containerize a small application.
- Use multi-stage builds and a non-root runtime where appropriate.
- Add health checks, persistent storage, and container networking.
- Scan and reduce image contents; document limitations.

## Evidence
Keep Dockerfiles, compose files, test instructions, and troubleshooting notes with the project that uses them. Competence is not assessed yet.
