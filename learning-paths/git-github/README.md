# Git and GitHub

## Outcomes
- Work with commits, branches, merges, tags, remotes, and conflict resolution.
- Use pull requests, code review, issue tracking, and release practices.
- Understand repository permissions and protect secrets.

## Practical work
- Practice a feature branch and pull request workflow.
- Resolve a merge conflict and explain the resulting history.
- Add contribution guidance and issue templates when useful.
- Demonstrate how to revert a bad change safely.

## Evidence
This repository is the initial hands-on workspace. The existence of a repository does not yet demonstrate proficiency in Git workflows.
