# Kubernetes

## Outcomes
- Explain cluster architecture, API objects, scheduling, controllers, networking, and storage.
- Deploy, update, scale, and troubleshoot workloads.
- Understand probes, resources, RBAC, configuration, secrets, and policy.

## Practical work
- Start with local cluster fundamentals.
- Deploy a multi-component application.
- Practice rollouts, rollbacks, resource limits, probes, service discovery, and persistent volumes.
- Inject failures and diagnose them using events, logs, and cluster state.

## Evidence
Keep manifests, Helm/Kustomize configuration, diagrams, and runbooks alongside each project. Competence is not assessed yet.
