# Linux and Networking

## Outcomes
- Navigate and inspect a Linux system confidently.
- Understand users, permissions, processes, services, storage, logs, and package management.
- Diagnose IP addressing, routes, DNS, ports, sockets, firewalls, and basic HTTP/TLS connectivity.

## Practical work
- Build a Linux lab and document how it is provisioned.
- Create and manage users, groups, permissions, services, and scheduled jobs.
- Diagnose deliberately introduced DNS, routing, disk, and service failures.
- Write a host/network troubleshooting runbook.

## Evidence
Record commands with explanations, expected output, environment details, and troubleshooting notes. Competence is not assessed yet.
