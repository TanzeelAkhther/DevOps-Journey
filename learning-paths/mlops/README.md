# MLOps

## Outcomes
- Understand reproducible data and model workflows.
- Version datasets, code, model artifacts, and experiment metadata.
- Build, test, deploy, monitor, and roll back a model-serving application.

## Practical work
- Create a reproducible training pipeline.
- Track experiments and model artifacts.
- Package a model behind an API and deploy it.
- Monitor service health and model-specific behavior; document retraining and rollback triggers.

## Prerequisites
Build software engineering, Python, containers, CI/CD, cloud, and observability foundations first. Competence is not assessed yet.
