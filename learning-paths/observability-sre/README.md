# Observability and SRE

## Outcomes
- Use logs, metrics, and traces to understand system behavior.
- Define service indicators and objectives.
- Diagnose incidents and communicate impact, mitigation, and follow-up work.

## Practical work
- Instrument a sample service.
- Build a dashboard and actionable alert.
- Define a simple SLI/SLO and explain its error budget.
- Run a failure exercise and write an incident report.

## Evidence
Keep dashboards, alert definitions, runbooks, and incident reports with the relevant project. Competence is not assessed yet.
