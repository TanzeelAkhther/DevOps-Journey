# Infrastructure and Application Security

## Outcomes
- Apply least privilege, identity and access management, secrets handling, network boundaries, patching, and secure defaults.
- Understand threat modeling, supply-chain risks, vulnerability management, and auditability.
- Build security checks into development and delivery workflows.

## Practical work
- Threat-model a small deployed service.
- Remove unnecessary privileges and harden container execution.
- Add dependency and image scanning to CI.
- Demonstrate safe secret injection and rotation without committing secret values.

## Evidence
Record threats, mitigations, test results, and accepted residual risks. Competence is not assessed yet.
