# Projects

Use this folder for end-to-end portfolio projects. Each project should have its own directory and a README describing its purpose, prerequisites, setup, architecture, validation, operations, and known limitations.

## Project lifecycle

1. Define the problem and acceptance criteria.
2. Create an architecture and threat model appropriate to the scope.
3. Implement in small, reviewable changes.
4. Automate tests and delivery.
5. Validate normal behavior and failure scenarios.
6. Document operation, recovery, cost, and security.
7. Capture a retrospective and evidence of independent work.
